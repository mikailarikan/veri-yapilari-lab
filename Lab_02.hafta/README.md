# Veri Yapıları Lab - 2. Hafta: Bağlı Liste (Linked List) Soruları

### Soru 1: Tek Node Oluşturma
Bir Node yapısı oluşturun. Node içerisinde 10 değerini saklayın ve ekrana yazdırın.

### Soru 2: İki Node'u Birbirine Bağlama
10 ve 20 değerlerini içeren iki Node oluşturun ve 10 -> 20 -> NULL listesini oluşturun.

### Soru 3: Üç Node'lu Listeyi Yazdırma
10 -> 20 -> 30 -> NULL listesini oluşturun ve while kullanarak tüm elemanları yazdırın.

### Soru 4: malloc Kullanarak Linked List Oluşturma
malloc() kullanarak 10 -> 20 -> 30 -> NULL listesini oluşturun.

### Soru 5: Listenin Eleman Sayısını Bulma
10 -> 20 -> 30 -> 40 -> NULL listesinin kaç Node içerdiğini bulun.

### Soru 6: Listenin Elemanlarını Toplama
10 -> 20 -> 30 -> 40 -> NULL listesindeki değerlerin toplamını bulun.

### Soru 7: Linked List'te Eleman Arama
Kullanıcının girdiği sayının 10 -> 20 -> 30 -> 40 -> NULL listesinde olup olmadığını bulun.

### Soru 8: Listenin Başına Eleman Ekleme
10 -> 20 -> 30 -> NULL listesinin başına 5 ekleyin. Sonuç 5 -> 10 -> 20 -> 30 -> NULL olmalıdır.

### Soru 9: Listenin Sonuna Eleman Ekleme
10 -> 20 -> 30 -> NULL listesinin sonuna 40 ekleyin.

### Soru 10: Belirli Bir Elemanı Silme
10 -> 20 -> 30 -> 40 -> NULL listesinden kullanıcının girdiği değeri silin.

### Soru 11: Fonksiyonlaştırılmış Linked List
Başlıca fonksiyonlar: insertBeginning(), display() ve search() fonksiyonları oluşturup;
* Listenin başına eleman ekleme fonksiyonu -> insertBeginning()
* Tüm listeyi gösteren fonksiyon -> display()
* Eleman ara -> search()
